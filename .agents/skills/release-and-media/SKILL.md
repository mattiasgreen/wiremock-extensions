# Release Management & Demo Media Pipeline Runbook

Orchestrates the automated release lifecycle with Googleapis Release Please, Maven Central publishing, and zero-bloat demo video asset hosting via GitHub Releases.

---

## 1. Release-Please Bot PR Approval & Merge

1. **Locate Pending Release PR**:
   ```bash
   gh pr list --head release-please--branches--main
   ```
2. **Approve Bot CI Run (if `action_required`)**:
   GitHub defaults to requiring maintainer approval for workflows triggered by `github-actions[bot]`:
   ```bash
   # Check if workflow requires approval
   gh run list --branch release-please--branches--main --limit 1

   # If status is action_required, approve immediately via API:
   gh api --method POST repos/mattiasgreen/wiremock-extensions/actions/runs/<run_id>/approve
   ```
3. **Wait for CI Completion**:
   ```bash
   gh run watch <run_id>
   ```
4. **Merge Release PR (Merge Commit, NOT Squash)**:
   > [!IMPORTANT]
   > Always merge release-please PRs with `--merge` (or GitHub web "Create a merge commit") to preserve the exact commit SHA and release manifest metadata generated by Release Please.
   ```bash
   gh pr merge <pr_number> --merge
   ```

---

## 2. Track Release & Maven Central Publication

1. **Watch Automated Release Workflow**:
   ```bash
   gh run list --workflow=release.yml --limit 1
   gh run watch <run_id>
   ```
2. **Verify Release Outcome**:
   - Tag created: `git fetch --tags` and `gh release list --limit 1`
   - Published JARs: `gh release view <tag>`

---

## 3. Demo Video Refresh & Zero-Bloat Asset Upload

1. **Generate Local Demo Tour Video**:
   ```bash
   ./gradlew :wiremock-examples:recordDemoVideos
   ```
   Output: `wiremock-examples/build/videos/banking/banking-progressive-simulation-tour.webm` (high-efficiency VP8/VP9 WebM).

2. **Upload Directly to GitHub Release (Zero Git Bloat)**:
   > [!WARNING]
   > NEVER commit binary `.webm` or large `.mp4` files into `main` git history. Always upload them as assets attached to the GitHub Release.
   ```bash
   gh release upload <tag> wiremock-examples/build/videos/banking/banking-progressive-simulation-tour.webm --clobber
   ```

3. **Deploy or Verify GitHub Pages**:
   If docs or UI assets changed:
   ```bash
   gh workflow run pages.yml
   ```
